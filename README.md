# 🧱 THINKBLOCK

**THINKBLOCK 회사 메인 홈페이지**  
THINKBLOCK의 코인 정보, 로드맵, 팀 멤버 등을 소개하는 **단일 페이지 기업 홈페이지**입니다.  
방문자가 프로젝트 전반(토큰, 비전, 팀 구성)을 한 화면 흐름 안에서 자연스럽게 이해할 수 있도록 설계된 랜딩/브랜딩 중심 웹 사이트입니다.

---

### 📘 프로젝트 개요
- **목적:** THINKBLOCK 프로젝트의 핵심 정보(코인, 로드맵, 멤버)를 웹 랜딩 페이지 형태로 제공  
- **특징:** 스크롤을 따라 내려가며 섹션별로 프로젝트의 스토리와 정보를 전달하는 단일 페이지 구조
- **작업기간:** 2022.01 ~ 2022.02  
- **작업참여도:** 퍼블리싱 100%  

---

### 🧱 제작방식
- **Frontend:** HTML + CSS + JavaScript  
- **Publishing:** 정적 페이지 퍼블리싱 기반, 인터랙션은 JS로 제어  
- **Size:** Desktop + Laptop + Mobile (반응형 퍼블리싱)  

---

### 🛠 주요 구현 내용

#### 🧭 페이지 & 섹션 구성
- THINKBLOCK 소개 섹션: 프로젝트 개요, 슬로건, 핵심 가치 등 브랜드 첫인상 영역
- 코인(토큰) 정보 섹션: 토큰 개요, 발행량, 활용처 등 핵심 정보 레이아웃 정리  
- 로드맵 섹션: 프로젝트 진행 단계와 계획을 타임라인/스텝 형식으로 시각화  
- 멤버(팀) 섹션: 핵심 구성원의 역할과 직책을 카드형 UI로 구성  
- 하단 푸터: 연락처, 관련 링크, 저작권 문구 등 기본 기업 정보 배치  

#### 🎨 퍼블리싱 & 인터랙션
- 시맨틱 마크업(`header`, `section`, `footer`)을 통한 기업 홈페이지 구조화  
- CSS Flex/Grid 레이아웃을 사용하여 카드형 블록, 타임라인, 정보 블록을 정렬  
- 스크롤에 따라 텍스트와 이미지가 순차적으로 등장하는 인터랙션(페이드/슬라이드) 구현  
- JavaScript를 활용한 메뉴 클릭 시 섹션 스크롤 이동, 활성 메뉴 상태 표시 등 기본 인터랙션 구성  

#### 📑 디자인 & UX 포인트
- 프로젝트 컬러 팔레트와 폰트를 일관되게 적용하여 브랜드 정체성 강화
- 정보량이 많은 구간(코인 정보, 로드맵)은 아이콘, 카드, 타임라인 등을 활용해 가독성 향상  
- 상단 고정 내비게이션 또는 섹션 인디케이터를 통해 현재 위치를 쉽게 인지할 수 있도록 구성  

---

### ⚙️ 기술적 포인트
- **반응형 퍼블리싱:**  
  - Desktop, Laptop, Mobile 해상도에 맞춰 그리드 재배치 및 폰트 사이즈 조정  
  - 모바일에서 단일 컬럼 중심으로 재구성해 가독성을 높이고, 터치 영역을 충분히 확보  
- **코드 구조:**  
  - 공통 컴포넌트(버튼, 카드, 타이틀 등)를 클래스로 재사용해 스타일 중복 최소화  
  - 섹션별 레이아웃 클래스를 분리해 유지보수성을 고려한 CSS 구조 설계
